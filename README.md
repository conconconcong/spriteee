# SPRITEEE

浏览器本地运行的一体化视频编辑与精灵图交付工具，采用单画布工作流。

## 使用方式

1. 双击打开 `index.html`。
2. 上传 MP4、MOV 或 WebM 视频，左侧画布用于视频与精灵图结果预览。
3. 在左侧预览中拖动画面定位、滚轮缩放，并在右侧依次完成裁时、裁画面、组合、倒放与变速。
4. 在“精灵图生成”区域选择 AI 抠像、总帧数或采样帧率、单帧尺寸与图片格式。开启抠像后会自动锁定为透明 PNG。
5. 先生成严格单行横排的原始精灵图，再按需执行独立的“精准压缩”，最后下载。

## 视频编辑

- 裁剪视频片段与时间范围
- 画面裁剪默认使用“自由”模式，四个角可独立拖动、宽高不锁定；也可切换为原始比例、16:9、9:16、1:1 或 4:5
- 预览框自动匹配视频或裁剪比例，完整显示横屏、竖屏及超宽视频
- 视频预览保持完整原画；拖动白色裁剪框调整位置，拖动四角改变选区大小，双击恢复完整画面
- 单画面、画中画、左右分屏与上下分屏组合
- 0.5×–2× 变速及倒放
- 精灵图专用 AI 人像抠像、毛发精修、边缘柔化与去色溢
- AI 抠像开启后在左侧画布实时预览，播放或拖动时间线时持续更新
- 自动识别蓝幕、绿幕等背景主色，对半透明毛发进行自适应边缘净色；可用“边缘净色”滑杆继续加强
- 若自动模式仍有残色，先点“主色取样”，左侧会出现像素放大镜；点击纯色背景后，工具会用中心 3×3 像素的中位数精准锁定色键
- 可点“＋ 加选”连续补充背景的阴影、亮部或其他颜色；净边时每个像素都会自动使用最匹配的色键，完成后再次点击“加选”退出
- 抠像结果可继续“加选主体”或“减去背景”：选择画笔大小后直接在左侧预览拖动涂抹，修补会同步应用到透明精灵图的全部帧
- 最终去除背景、保留主体与毛发边缘，并导出带 Alpha 通道的透明 PNG（不会改变视频导出）
- 单帧尺寸预设为 S 375px、M 750px、L 1125px、XL 1500px，默认使用 M 750px
- 超宽精灵图不再受浏览器单张 Canvas 宽度限制：左侧仅显示缩略预览，下载仍按全部帧与单帧尺寸交付完整宽度
- 例如 48 帧 × 750px 可导出 36000px 宽的单行 JPG 或 PNG；超宽 WebP 会自动改用 JPG，只有透明抠像或总宽超过 JPG 的 65535px 格式上限时才使用 PNG
- 压缩与生成分离，不再设置目标文件上限，也不会为了压缩而改变精灵图尺寸
- 压缩程度可在 10%–100% 之间调整，默认 35% 均衡档；JPG/WebP 的实际编码画质可从约 95% 降到 6%，高压缩档会显著减小文件
- 透明 PNG 的“精准压缩”采用像素级无损优化：不缩图、不减少颜色、不改 Alpha，若原文件已是最优大小会直接保留
- JPG 通常更小但不支持透明通道；需要保留抠像后的透明背景时必须使用 PNG，因此无损压缩的体积降幅会相对有限
- 导出 WebM 视频
- 视频编辑与精灵图参数在同一右侧面板，左侧只保留一个预览框

AI 抠像首次使用时需要联网下载 MediaPipe 人像与毛发模型。模型加载后在浏览器本地运行，视频素材不会上传。倒放及合成视频导出暂不保留原音频。

推荐使用最新版 Chrome、Edge 或 Safari。若浏览器限制本地视频读取，可在此目录启动任意静态文件服务后访问。
